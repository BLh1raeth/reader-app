# Data / 数据页视觉重构 —— 给 Codex 的精确提示词

（用户原话：目标只有一个，尽量还原前面生成图的视觉语言，不要再让它自由发挥。）

---

请把 Data / 数据页 继续重构为下面这套视觉规范，目标是高度贴近参考图的风格：整体更接近 Apple Health / 睡眠评分卡片式信息架构，但内容必须是“阅读数据”，不是睡眠数据。

一、总目标

本次不是小修小改，而是统一整页的视觉系统。
请基于当前 Data 页面，改成：

* 浅灰背景
* 多张白色大圆角卡片
* 标题层级清晰
* 高饱和重点色 + 柔和图表色
* 更像“信息卡片仪表盘”
* 图表样式更接近我给的参考图
* 顶部大卡记录“今日阅读”
* 中部两张小卡分别做阅读时长 / 阅读速度
* 底部一张大卡做“阅读节奏 / 阅读摘要”
* 所有字体、颜色、间距、圆角、线条、图形风格都要统一，不要现在这种“部分像参考图、部分又像原来页面”的混搭感。

---

二、整体页面样式

1. 页面背景

* 整页背景色改为：#F3F2F7
* 不要纯白背景，也不要偏蓝灰，保持很轻的 iOS 风格浅灰底。

2. 页面主标题

* 顶部主标题文字：数据
* 字体：超大号、粗黑、接近 iOS 大标题风格
* 颜色：#111111
* 建议：
    * fontSize: 30~34
    * fontWeight: 900
    * lineHeight: 略紧凑
* 左右边距统一，不要过宽也不要过窄。

3. section 标题

例如：

* 最近 7 天
* 摘要

样式统一为：

* 颜色：#111111
* 字重：800~900
* 字号：20~22
* 与上下卡片要有明显留白。

---

三、卡片总规范

所有数据卡片统一：

* 背景色：#FFFFFF
* 圆角：28
* 不要描边
* 阴影极轻，几乎没有，优先靠背景反差区分层级
* 内边距：24
* 卡片之间垂直间距：18~22
* 两列小卡之间水平间距：16
* 所有卡片内容都要更“规整”，不要零散地漂在卡片内部

---

四、顶部大卡 —— 今日阅读（最重要）

这个卡片必须参考我喜欢的那张生成图的结构。

1. 卡片内容结构

左侧放文字摘要，右侧放圆环图。

左侧内容顺序：

1. 小标题：今日阅读
    * 颜色：#4A8CFF
    * 字号：16~18
    * 字重：700~800
2. 主状态大字：刚开始
    * 颜色：#111111
    * 字号：34~40
    * 字重：900
3. 三行指标，前面带彩色圆点：
    * 蓝点 + 时长：< 1 分钟
    * 青点 + 字数：751 字
    * 橙点 + 摘录：1 条

这些三行指标统一：

* 文本颜色：#111111
* 字号：16~18
* 字重：700~800
* 行距舒展一点
* 前面的彩色圆点要实心圆

彩色圆点颜色固定为：

* 时长蓝：#3F83F8
* 字数青：#57C7D4
* 摘录橙：#F39A3E

4. 下方一条细分割线

* 颜色：#E9E9EE

5. 分割线下方说明文案：
    * 今天你已经阅读了 751 字，并记录了 1 条摘录。
    * 颜色：#111111
    * 字号：16~18
    * 字重：700
    * 风格要像参考图的“总结句”，简短有力

2. 右侧圆环图

这个圆环一定要像参考图，不要做成普通进度环。

样式要求：

* 外环底色：#EAEAEA
* 圆环线宽：较粗
* 圆角端点
* 用 3 段彩色弧线分布在环上，视觉上类似参考图
* 中间显示：
    * 第一行：2/7
    * 第二行：天

圆环配色：

* 青色弧段：#57C7D4
* 橙色弧段：#F39A3E
* 蓝色弧段：#3F83F8

中间文字：

* 2/7
    * 颜色：#111111
    * 字号：26~30
    * 字重：900
* 天
    * 颜色：#111111
    * 字号：16~18
    * 字重：700

注意：
这个圆环的意义是“最近 7 天中有 2 天阅读”，所以视觉上要体现 7 天中的 2 天活跃感，但表达方式仍然保持参考图那种“睡眠评分圆环”的感觉，而不是普通仪表盘。
