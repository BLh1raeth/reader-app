# 阅读器改进验收

本轮保留数据页模拟数据和笔记占位，不连接真实数据 UI，不实现 iCloud 同步或用户字体文件导入。字体新增系统、宋体、黑体选项，实际字形依设备可用字体回退。

## 自动验证

使用 Node.js 24，运行 `npm ci`、`npm run typecheck`、`npm test`。浏览器测试需安装 Playwright Chromium：`npx playwright install chromium`，然后 `npm run test:browser`。`npm run export:ios` 验证 Hermes 和 DOM 生产产物；它设置 Expo SDK 57 当前需要的 `EXPO_NO_BUNDLE_SPLITTING=1`。

- 数据库从每个迁移事务边界中断后继续升级至 v23；误标为 v21、但缺少设置列的旧库会被修复。
- 移除本地文件保留摘录、会话等数据；实际重导入流程保持原 id、标题、标签和状态，写到新文件路径；遗留清理任务不会删除恢复文件。
- 永久删除关联摘录和新速度样本；事务失败保留原文件，文件删除失败留在重试队列。老版本匿名速度样本无法还原到具体图书，保留在全局历史中。
- 备份读取资源时检查实际解压长度、CRC32 和 EPUB SHA-256；失败不提交。覆盖缺少文件、错误资产内容、伪造解压大小及 SQLite 提交失败。
- 导出分块读文件，验证正常 ZIP 往返、进度、取消与写入失败清理。取消接口供后续 UI 使用，本轮菜单只有进度提示。
- 正向计数不因往返翻页重复增加；测量队列顺序和退出后的结算、跳转分段、速度按有效时间归一化、延迟闲置计时均有回归覆盖。
- 摘录编辑保持 CFI 和创建日期；标签、搜索、外观和字体持久化有覆盖。分页缓存每本书最多保留 3 个布局，并行统计读取只合并正在进行的请求。
- 原生菜单插件在锁定的 Expo 依赖上测试补丁目标、重复执行、版本不匹配和部分补丁；任一目标不匹配时在写文件前失败。
- 高亮点按上报原文、CFI 和经过一次 iframe 映射的锚点；点击不翻页、不切换工具栏、不生成网页删除气泡。删除成功后清除绘制，失败保留高亮；旧菜单回调、换书与打开阅读面板均不会误删，高亮原文可直接保存为摘录。
- iframe 替换过程中，分页器的布局回调等待 documentElement / body 就绪；浏览器回归显式移除 body，复现上游空 style 错误并确认适配器不会执行该次布局。
- Chromium 使用实际 Foliate 适配器测试 EPUB 2/3 的按需加载和兼容加载：脚本/事件处理器不执行，远程图片不请求，本地图片及嵌套 CSS 正常；中文分页、脚注、字体重排的可见锚点和关闭后 CFI 恢复正常。

| --- | --- | --- |

Linux 上的 prebuild、类型检查和 JS 导出不能证明 Swift 编译或 WKWebView 行为。高亮点按菜单使用自研 Swift 模块，**不得在 Expo Go 中验收**；必须安装包含更新后模块的新 development build。

### 高亮点按原生菜单：真机验收清单

高亮点击不再生成网页内的暗色“删除”气泡。公开 UIKit `UIEditMenuInteraction` 通过只读、透明的原生文本 responder 提供系统 Copy / Lookup / Translate 动作，与 WKWebView 选词菜单共用 `ReaderEditMenuCoordinator`，只在高亮菜单中将“高亮”替换为 `.destructive` 的红色“删除”。未包含新版原生模块的开发包不恢复网页气泡，需要安装新包后验收。

- [ ] 与选词菜单逐项对照：摘录 / 添加笔记 / 在本书中搜索，以及 Copy / Lookup / Translate 等系统项保持原行为，只有“高亮”变为红色“删除”。添加笔记仍为现有占位。
- [ ] Copy 使用原生 `UIPasteboard`；Lookup / Translate 处理被点击高亮的原文，系统项及其语言、设备可用性与选词菜单一致。
- [ ] 点“删除”立即收起菜单，无二次确认；数据库写入成功后移除高亮，重新开书确认删除已持久化。写入失败时高亮保留并提示错误。
- [ ] 菜单贴近被点击的高亮行：覆盖边缘、跨行及跨页高亮、横竖屏、不同字号/边距和分页重排。iframe 局部矩形映射为 WKWebView viewport 坐标，原生 responder 直接位于该 WebView 中，不再叠加窗口 / safe-area 偏移、分页 transform 或设备像素倍率。
- [ ] 切换书籍、翻页、打开 settings / 搜索、点击菜单外部后正确收起；再次长按选词仍显示“高亮”，延迟回调不会删除另一条高亮或另一本书的内容。
- [ ] EAS development build 的 Swift 编译成功，安装新包后逐项验收。类型检查、config plugin 补丁测试与浏览器 EPUB 回归通过不能替代真机结果。

### 其余真机场景

| 场景 | 预期 |
| --- | --- |
| 安装新包并启动已有书库 | 旧记录升级后可见，设置保留；无需卸载旧包 |
| 系统浅/深色切换、手动外观选择 | 阅读背景、目录、玻璃控件和文本可读，退出再打开保留设置 |
| 字体、字号、边距反复修改 | 阅读锚点保持，页数按新布局重算，不增加跳转字数 |
| 目录/搜索/书签跳转后返回 | 返回按钮回到上一个阅读位置，多次跳转可逐次返回；正常翻页不增加历史栈 |
| 书库网格/列表、快速滚动、批量选择、拖动排序 | 触摸与封面开书过渡正常，筛选后排序不丢失隐藏图书 |
| 长按摘录复制/分享/编辑/删除、筛选后导出 | 系统剪贴板和分享面板正常，编辑后原文定位仍可用，导出只包含可见结果 |
| 移除文件、重导入同一 EPUB、永久删除 | 移除后在“已移除本地文件”筛选中可见；重导入保留记录；永久删除准确提示影响 |
| 导入大图 EPUB、多本导入、备份导入/导出 | 进度提示可见，存储不足有提示，失败不会清空原书库 |
| 前后台、锁屏、10 分钟闲置、午夜跨日 | 会话边界和日期归属正确；不把后台或超出闲置阈值的时间算入阅读 |
| 真实 EPUB 样本 | 图文、中文标点、脚注、嵌入字体、EPUB 2 NCX、固定版式分别抽检；离线阅读不依赖书内远程资源 |

升级前可先导出本地备份。v23 备份需要支持 v23 的应用恢复，旧版应用会拒绝较新格式的数据库。真机尚未验收的项目不视为已通过。
